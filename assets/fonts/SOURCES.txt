FUSED PROTECTIVE SERVICES — SELF-HOSTED WEB FONTS
=================================================

These files are third-party binaries. They are committed rather than fetched
because SPEC-006 puts the marketing site behind `default-src 'self'` with no
allowlisted origins: the page that collects a client's name, phone number and
the location and schedule of a protective detail must not let a third party
run script or serve bytes into it. `font-src 'self'` is only honest if the
fonts are actually ours to serve.

WHERE THEY CAME FROM
--------------------
Every file below is a byte-for-byte copy of what Google Fonts served for the
exact request the site used to make from its <head>:

  https://fonts.googleapis.com/css2
      ?family=Cinzel:wght@600;700;800;900
      &family=Outfit:wght@300;400;500;600;700;800;900
      &family=JetBrains+Mono:wght@400;500;600;700;800
      &display=swap

fetched with a current Chrome user agent, which is what makes Google answer in
woff2. Nothing has been re-encoded, subsetted or instanced by us.

WHY TEN FILES COVER SIXTEEN WEIGHTS
-----------------------------------
All three families are variable fonts. Google answers that request with 52
@font-face blocks pointing at only 10 distinct files: one per family per
unicode-range subset, each carrying the whole wght axis. Every declared weight
is an instance of the axis, so `font-weight: 600 900` in src/styles/base.css
covers exactly the weights the site asked for and nothing extra. (Verified: all
ten files carry an `fvar` table.)

The non-Latin subsets are kept even though no glyph on the site needs them.
They cost 23,236 bytes of repository and ZERO bytes over the wire — the
unicode-range on each @font-face means a browser only fetches a subset when it
is about to paint a character from it. Dropping them would save nothing a
visitor can measure and would silently downgrade a Cyrillic or Vietnamese name
typed into the quote form to a system fallback.

LICENCES
--------
All three are SIL Open Font License 1.1, which permits self-hosting and
redistribution. The full licence text for each is committed alongside:

  cinzel-OFL.txt          Copyright 2020 The Cinzel Project Authors
  outfit-OFL.txt          Copyright 2021 The Outfit Project Authors
  jetbrains-mono-OFL.txt  Copyright 2020 The JetBrains Mono Project Authors

Note for anyone updating this directory: OFL 1.1 forbids selling the fonts on
their own and forbids using the Reserved Font Names on a modified version. We
do neither — we serve them unmodified as part of the site.

run, so a corrupted, truncated or quietly swapped font fails the test suite
instead of shipping.
