What this prototype is

One THREE.Points cloud, one draw call, driven by four shader uniforms. The site plan is synthetic — a generic yard, building footprint, fence line and access drive. No real client geometry, deliberately: displaying a drone-captured image of private real property can implicate Tex. Gov't Code §423.004.

There are no detection markers and no timestamps. Fused has not run this service yet, so any incident shown here would be invented. The fourth beat sells the drone-to-officer handoff instead, which is true on day one.

Every number in the envelope row is a TBC placeholder and is flagged red by default, following the repo's fail-closed placeholder rule (SPEC-001). They are not guesses; they are blanks waiting on Cameron.
